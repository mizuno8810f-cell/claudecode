Sound effects (SE). Filenames are configured in src/data/game.json under
config.sounds — swap these files (any browser-playable format) to change the SE.
Missing files fail silently.

These .wav files are simple synthesized placeholder tones; replace them with
real SE when available. Keys: touch, itemGet, itemUse, doorOpen, correct,
wrong, zoomIn, zoomBack, popupOpen, popupClose, videoStart, clear.
